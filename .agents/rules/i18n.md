# Regla Invariable: Internacionalización (i18n)

1. Todo texto visible en la web debe provenir de `src/locales/es.json` y `src/locales/en.json`.
2. Queda estrictamente prohibido introducir cadenas literales (hardcoded strings) en los componentes JSX/TSX.
3. Si se añade una nueva clave en español, obligatoriamente se debe añadir su equivalente en inglés con idéntica estructura jerárquica.
4. El script `npm run i18n:check` valida la paridad de claves y fallará si hay claves huérfanas, duplicadas o no sincronizadas.
